**Change summary:** Adds repo-wide `before=2026-10-21T00:00:00.000Z`, so any npm resolution of a version not already in the lockfile ignores packages published after that date. Reason given: `@types/sinon 22.0.1` broke the appium driver's `prepare` build.
**Assessment:** Not a vulnerability. `npm ci` follows the lockfile, so CI and shipped builds are unaffected. Two side effects: (1) `npm install`/`npm audit fix`/Dependabot-style bumps for crypto or security packages cannot pick up anything published after 2026-10-21 while this file stands, so a fresh security patch would silently fail to resolve; (2) it is labelled temporary but has no expiry or tracking issue. The "Deps: run `npm audit` on any package.json change" rule is weakened for the same reason.
