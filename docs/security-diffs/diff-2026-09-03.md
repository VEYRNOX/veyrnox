### `src/lib/useAdvisorSnapshot.js:20-31`, `src/components/SecurityAdvisor.jsx:1341-1369`, and new page callers — **REGRESSION**
**Commit:** `20ae570d feat(vigil): per-page awareness — 7 route mappings + snapshot on 61 pages (#2271)`

**Change summary:** A generic `useAdvisorSnapshot()` publisher now forwards 61
pages' shell-state objects to the Advisor. The Advisor includes those objects in
the remote prompt and request context after `hasAdvisorConsent()` succeeds.

**Assessment:** The consent disclosure at `SecurityAdvisor.jsx:1544-1549`
promises only typed questions, the current screen, and selected chain. The new
payload materially exceeds that statement: examples include Dashboard's wallet
and transaction counts, Spending Patterns' sent/received counts, Address Book's
contact count, Audit Log's entry count, Biometric Auth's enabled factor, and
Subscription's tier/billing/referral state. These facts travel with the
persistent `device_id` at `SecurityAdvisor.jsx:1362-1369`, making disclosure to
the I5-untrusted backend per-device and durable.

No raw address, balance, seed, PIN, key, or transaction signature was found in
the current new caller payloads. The hook drops its snapshot when
`isDeniabilityOrDemoActive()` is true, so this finding does not claim a current
I3 bypass. It is an I2/I5 and I4 honesty regression: an existing grant is not
informed consent for the new, broader remote payload.

**Required resolution:** Keep snapshots local or reduce the remote payload to
the consented screen-and-chain shape; alternatively, revise the disclosure to
enumerate the new categories and invalidate prior grants for a fresh choice.
Add a schema/allowlist test over every `useAdvisorSnapshot()` caller. The
existing `advisorContext.noCoercionOracles.test.js` parses only literal
`publishAdvisorContext({ ... })` calls, so it misses these 61 objects and would
not catch a future `duress`, `stealth`, or `decoy` field passed through the hook.

**Not verified:** static source trace only; no production wire capture, device
test, or on-chain verification was performed.
