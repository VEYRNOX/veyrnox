### `src/lib/WalletProvider.jsx:659-682`, `src/pages/BuyCrypto.jsx:117-176` — SAFE (deliberate, bounded reduction in lock protection)
**Commit:** `4a39a87e` fix(buy): pause wallet idle lock during Transak checkout (#2763), 2026-09-24T17:42Z
**Change summary:** A new `withBuyLockSuppressed` in `WalletProvider` pauses the
**wallet idle-lock countdown** (`armTimer` returns early while any Buy
suppression is registered) as well as the native background lock
(`withLockSuppressed`), for the length of a native Transak checkout. Before this,
Buy only suppressed the native background lock.
**Assessment:** This is a real, deliberate widening of the time the wallet stays
unlocked behind an external browser. The idle timer no longer runs during
checkout. Read in full, it is bounded and fails closed:
- **Bounded:** `BUY_LOCK_SUPPRESS_MAX_MS = 15 min` (`BuyCrypto.jsx:52`). The
  timeout now calls `finish(); lock();`, so it **locks the wallet** at 15
  minutes. Before, it only ended suppression. On that path this is stricter than
  before.
- **Cancellable:** `lock()` cancels every registered Buy suppression and clears
  the set (`WalletProvider.jsx:558-562`). So duress, panic, deniability
  activation, RASP-WARN and manual lock all still end it. The `finally` re-arms
  the idle timer only if its own cancel was still registered, so a stale
  purchase cannot reset a later session's timer.
- **Absolute ceiling untouched:** the VULN-18 `MAX_SESSION_MS` timer is separate
  and is not affected by `buyLockSuppressions`.
- **Fail closed:** it refuses to start while locked (throws). If the timeout
  cannot be armed, it now throws instead of silently continuing. It no longer
  opens the browser when the `browserFinished` listener fails to register
  (pinned: "does not open without the browser close listener"). Unmounting the
  page releases suppression.
- **Tests:** `BuyCrypto.lockSuppression.test.jsx` and the new
  `WalletProvider.buySession.test.jsx` only add assertions. No skip deltas.

*Observation:* the 13-line "SECURITY NOTE, stated rather than buried" comment in
`BuyCrypto.jsx`, which spelled out the minutes-long unlocked window "including if
the device is put down or handed over", was cut to 5 lines. The shorter comment
still says the wallet "deliberately retains the unlocked wallet behind the
browser until close or the 15-minute limit", so the trade-off is still disclosed
at the call site, just less emphatically. Not a finding.

Transak / Buy is owner-only (`CLAUDE.md`). This entry reports and changes
nothing. The commit is authored by the owner's account.
