## Recommended actions

1. **No dependency change needed for security.** Zero critical, high, or
   moderate. `npm audit fix` has nothing safe to do — all 5 findings report
   `fixAvailable: false`, so Step 6 of the runbook does not apply and no
   `fix/dep-audit-*` branch was opened.
2. **Keep the `elliptic` residual as re-scoped.** Do not retire it and do not
   downgrade the Keystone SDK to chase it. All four watcher signals and both
   reachability triggers re-checked negative above.
3. **The `@noble` / `@scure` 2.x line is a reviewed cryptography change, not a
   version bump.** Six packages, four of them major, all on the
   seed/derivation/signing path, none carrying an advisory. Schedule it
   deliberately with compatibility tests — never via a grouped Dependabot PR.
   Note that `ethers` 6.17.0 pulls its own `@noble` versions; bumping ours to 2.x
   without checking that interaction risks two copies of the curve library in one
   bundle.
4. **The caret-admitted updates are free and unreviewed-by-nobody:**
   `@walletconnect/sign-client`, `@walletconnect/utils`, and all four
   `@capacitor/*` already sit inside their declared ranges. A lockfile refresh
   picks them up with no `package.json` edit. `@walletconnect/core` is pinned
   exact, so 2.24.0 there is a deliberate decision, not a refresh — take all three
   WalletConnect packages together or none, so the family does not split versions.
5. **Nothing else is security-critical.** The other 18 outdated packages are
   tooling and UI (`eslint`, `tailwindcss`, `date-fns`, `lucide-react`, `@wdio/*`,
   `zod`, …), none with an advisory.
