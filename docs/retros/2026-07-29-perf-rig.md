## Lessons worth carrying forward

1. **Read `ci.yml` before writing any new workflow that runs `npm ci`.** The
   npm 11 pin was documented right there in an inline comment. Two failed
   iterations for a search never done.
2. **Cut a fresh worktree from `origin/main` *before* believing "main is
   broken."** One commit away from opening a lock-fix PR on `main` when the
   lock was already fine — the perf branch was just stale. The shared-checkout
   rule already says this; the missing piece is the diagnostic order:
   **if the symptom is "package-lock is out of sync," reproduce on a fresh
   `origin/main` worktree before touching main.**
3. **Playwright `page.evaluate` is not a substitute for LHCI on heavy SPA
   cold-loads.** LHCI works because it drives CDP directly; evaluate races
   the app's main thread. For any SPA with meaningful cold-start JS, plan
   on CDP-based measurement from the start (or Playwright's tracing API,
   which is also CDP-backed).
4. **Scope-cut earlier.** The Playwright cut happened after 6 iterations;
   should have been after 3 — the same fundamental error (page/JS-thread
   blocked evaluate) recurring under three different `waitUntil` choices
   was already saying the approach was wrong, not the parameter.
5. **Path-scoped `pull_request` triggers on workflows that need secrets are
   a footgun.** They add a check every PR must satisfy, but can't succeed
   without the secret. Wire the secret first, then add the trigger.
6. **`continue-on-error: true` during calibration is a legit pattern.**
   Let all stages run in one CI round so you can tune from complete data
   rather than iterate. Reach for it the next time a workflow is being
   calibrated.
7. **Watch for the `mkdir`-after-write class of shell-step bug.**
   `bash -e` + a `nohup redirect > path/file` before `mkdir -p path` =
   silent step failure. Belongs in a mental checklist for reviewing any
   shell step that writes files.

## What worked

- **Shared-checkout discipline held for the whole session.** All work in the
  branch worktree; the primary checkout was never touched. Zero
  cross-contamination with other sessions.
- **Fail-closed guards paid off.** k6's staging-URL check and staging-secret
  check both fired correctly — no half-runs, no partial data.
- **Honest scope cut.** Cutting Playwright specs was the right call; the PR
  shipped clean the same day instead of dragging through a CDP rewrite.
- **PR description honesty.** Updated the body after the scope cut so
  reviewers see what actually shipped, not what was originally planned.

## Score

**~65% efficient.** 3 hours of productive work + ~1.5 hours avoidable churn.
Landed a working, honest rig. Two lessons (read `ci.yml` first; diagnose
main before assuming it's broken) would have saved 3 iterations. One
structural lesson (Playwright/CDP for SPA cold-load) is a genuine new
insight worth carrying forward — not avoidable without specialised
background.
